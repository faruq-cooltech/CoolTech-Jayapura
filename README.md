# COOLTECH JAYAPURA — starter aplikasi manajemen

Aplikasi web responsif untuk pelanggan, order servis AC, transaksi dan laporan bulanan.

Mulai dari `SETUP.md`. Database schema dan Row Level Security ada di `supabase.sql`. Konfigurasi browser ada di `config.js.example` (salin menjadi `config.js`).

**Jangan pernah masukkan Supabase `service_role` key di file frontend.**
